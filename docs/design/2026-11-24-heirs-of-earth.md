# Dünyanın Mirasçıları (Heirs of Earth) 0.1 → 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the RimWorld 1.6 mod "Heirs of Earth" from nothing up to its 2.0 content: Harmony bootstrap, Culture Knowledge, the "World Heritage" research tab, six nations (Nova Roma, Yamato, Nordheim, New Hellas, Tianxia, Albion), traditions, living world politics, six story chains, the Heirs tab, scenarios and settings, all in English and Turkish.

**Architecture:** A small C# core (knowledge, traditions, politics, chains, UI, isolated Harmony patches) driven entirely by data. All nation content (defs, Turkish translations, textures) is generated from one Python data module, the same way Starfall's `sf4_*.py` tools work. Each milestone (0.1, 1.0, 2.0) ends with offline checks and one in-game probe run that must be clean.

**Tech Stack:** C# 9 compiled with the SDK's Roslyn `csc.dll` against `RimWorldWin64_Data\Managed` and Harmony's `0Harmony.dll`; Python 3.13 + PIL + numpy (`python -I`) for generators and art (`tools/kut_render.py` renderer, `tools/heirs_style_sample.py` style); PowerShell for build, validation and the test launcher.

**Spec:** `docs/superpowers/specs/2026-11-24-heirs-of-earth-design.md`

## Global Constraints

- RimWorld 1.6.4871, Core only. Harmony `brrainz.harmony`, compile against `C:\Program Files (x86)\Steam\steamapps\workshop\content\294100\2009463077\1.6\Assemblies\0Harmony.dll`; never ship `0Harmony.dll` in the mod.
- Mod folder `HeirsOfEarth/`, packageId `kerem.heirs`, author `Kerem`, name "Heirs of Earth" (Turkish: "Dünyanın Mirasçıları"). `modDependencies` and `loadAfter` list `brrainz.harmony`.
- `LoadFolders.xml` from day one (root + `1.6`), so DLC folders can be added after 1.0 without restructuring. No DLC content before 1.0.
- Def prefix `HE_`; C# namespace `HeirsOfEarth`; Harmony id `kerem.heirs`; log prefix `[Heirs]`.
- No modern countries, real people, brands; no religion shown negatively; no Turkic or Mongol nation. Names are generated from period-flavoured syllable/name banks, never named historical persons.
- Every Harmony patch lives in its own class, is applied inside try/catch, logs one line on failure and disables only its feature. Postfix preferred; no Transpilers.
- Every new power comes with a cost or a choice; weapon/armor/research numbers stay inside the vanilla ranges printed by the balance table (Task 6).
- Full English and Turkish text. Turkish goes to `Languages/Turkish (Türkçe)/DefInjected` and `Keyed`; CompUsable labels use `comps.CompUsable.useLabel` paths.
- Art: vanilla look — dark outline, soft volume shading, light grain, limited palette, light from top-left — drawn by code with `kut_render`. Keep no unused images or temp files.
- Project is not a git repo: "checkpoint" steps mean running the milestone checks, not committing.
- The game is launched only through the test launcher (Task 7), one launch per test run, never while another instance runs. Steam publishing of this new mod needs the user's explicit OK and is not part of this plan.

## Review Focus

1. Existing save without the mod's components (mod added mid-game): game must load, heritage window must offer a one-time choice, nothing may null-ref. → probe check `save_without_heirs_component` (Task 7).
2. A Harmony target that fails to patch (signature changed by another mod): the game keeps running, that feature switches off, one `[Heirs]` warning line. → probe check `patch_failure_isolated` (Task 2) using a deliberately broken test patch.
3. A nation faction destroyed or missing (other mods removing factions, faction count limits at world gen): politics, chains and knowledge must skip it silently. → probe check `politics_survives_missing_faction` (Task 12).
4. Research already in progress when its gate stops being met (knowledge setting changed): the project continues; only starting is gated. → probe check `gate_does_not_cancel_current` (Task 3).
5. Settings changed mid-game (tradition group off, politics off): effects disappear on the next stat recalculation, no stale cached bonus. → probe check `tradition_toggle_clears_bonus` (Task 9).

## Interfaces shared by all tasks

```csharp
namespace HeirsOfEarth {
  public class NationDef : Def { public Color color; public FactionDef faction; public FactionDef playerFaction;
    public ScenarioDef scenario; public ThingDef archive; public string rulerTitle; public string adjective;
    public int release; public List<NationDef> friends; public List<NationDef> rivals; public string iconPath; }
  public enum EffectScope { Colonists, PlayerBuildings }
  public class StatEffect { public StatDef stat; public float offset; public float factor = 1f; public EffectScope scope; }
  public class HeirsResearchExt : DefModExtension { public NationDef nation; public float knowledge; public bool tradition;
    public List<StatEffect> stats; public float qualityChance; public float caravanSpeed; public ChainDef requiresChain; }
  public class HeirsCultureExt : DefModExtension { public NationDef nation; public float knowledge; }   // ThingDef, BackstoryDef
  public abstract class HeirsPatch { public abstract string Id { get; } public abstract void Apply(Harmony h); }
  public static class HeirsPatches { public static bool Active(string id); public static IReadOnlyDictionary<string,bool> Status; public static void ApplyAll(); }
  public class HeirsGame : GameComponent { public static HeirsGame Get; public NationDef heritage; public bool heritageChosen;
    public float Knowledge(NationDef n); public void AddKnowledge(NationDef n, float amount, string reasonKey);
    public bool CanStart(ResearchProjectDef p, out string reason); public void SetHeritage(NationDef n /* null = independent */);
    public List<ChronicleEntry> chronicle; public ChainState State(ChainDef c); }
  public static class HeirsTraditions { public static bool Active(ResearchProjectDef p); public static void Dirty(); }
  public class HeirsWorld : WorldComponent { public static HeirsWorld Get; public bool AtWar(NationDef a, NationDef b);
    public bool Allied(NationDef a, NationDef b); public void DeclareWar(NationDef a, NationDef b); public void MakePeace(NationDef a, NationDef b);
    public Faction FactionOf(NationDef n); public void MonthlyTick(); }
}
```

Test harness conventions (Task 7): `P.Check(string name, bool ok, string detail = "")`, steps queued as `Steps.Add(("name", Action))`, log lines prefixed `HETEST`, final line `HETEST SUMMARY pass=N fail=N errors=N untranslated=N missingTex=N`. A run is clean only when fail, errors, untranslated and missingTex are all 0.

### Task 11: Basic world politics

### Task 12: Story chains engine + three chains

**Files:** `Source/Chains/HeirsChains.cs`, `Source/Chains/HeirsSites.cs`; data `ChainDef` per nation.

`ChainDef : Def` { `NationDef nation; List<ChainStep> steps; ThingDef artifact; ResearchProjectDef unlocks;` } and `ChainStep` { `StepKind kind (Deliver, Build, Research, Raid, Site, Choice); List<ThingDefCountClass> things; ThingDef building; ResearchProjectDef project; PawnGroupKindDef group; float points; string siteLayout; List<ChoiceOption> options; string text` }. Chain starts when knowledge of the nation ≥ 60 or heritage = nation; one step active at a time; Deliver consumes from player home maps via a button in the Stories section; Raid spawns a raid of the nation's rival with `points`; Site creates `HeirsSite : MapParent` (map gen cribbed from `StarfallCore/Source/StarfallSites.cs`: ruins, guards of the given faction, reward item; completes when reward is in a player map or caravan). Final step gives artifact and finishes the chain (unlocks top project via `requiresChain`).

Chains: Roma "The Lost Eagle" (deliver 200 steel + 4 gladii → build Standard → raid by rival → site: ruined fort → choice: return eagle to the Senate (+40 goodwill, research unlock) or keep it (artifact stronger, −30 goodwill)). Yamato "The Broken Dynasty" (deliver tea + silk → research Forged Folds → duel raid (one Hatamoto champion) → site: mountain shrine → choice: restore heir / take the sword). Nordheim "Winter Rite" (deliver 30 pemmican + furs → build Rune Stone → survive cold-snap with raid → site: ice barrow → choice: blow the horn now / give it to the Jarl).
